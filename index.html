CONTRIBUTION GUIDE

Hướng dẫn đóng góp

Mọi đóng góp đều được review trước khi đưa vào ngân hàng chung. Bạn có thể gửi thay đổi trực tiếp bằng Pull Request hoặc tạo Issue để nhóm dự án hỗ trợ chuẩn hóa.

CÁCH 1

Fork repository và tạo Pull Request

  1. Fork repository forlanguage/forlanguage.github.io.
  2. Tạo branch mới, ví dụ feat/add-aptis-reading-questions.
  3. Cập nhật nội dung, ghi rõ nguồn, loại câu hỏi và đáp án đề xuất.
  4. Commit, push branch và mở Pull Request về nhánh main.
Fork repository
CÁCH 2

Tạo Issue theo đúng loại

Issue phù hợp khi bạn có dữ liệu cần đóng góp nhưng chưa muốn chỉnh sửa source code trực tiếp.

Đóng góp câu hỏi Dành cho bộ câu hỏi thực tế sau khi thi hoặc tài liệu luyện tập có giá trị. Sau khi review và chuẩn hóa, nội dung phù hợp sẽ được bổ sung để tăng số lượng câu trong ngân hàng. Report đáp án sai Gửi Question ID, đáp án hiện tại, đáp án đề xuất và lý do. Có thể dùng nút “Báo lỗi” ngay bên cạnh mỗi câu trong Aptis Practice để sao chép thông tin.
Lưu ý về câu hỏi thực tế sau kỳ thi

Đây là nguồn đóng góp rất giá trị. Hãy ghi lại theo trí nhớ bằng cách diễn đạt của bạn, tránh đăng thông tin cá nhân, dữ liệu thí sinh hoặc nội dung mà bạn không có quyền chia sẻ. Nhóm dự án sẽ kiểm tra, viết lại và chuẩn hóa trước khi đưa vào ngân hàng.
