# M6.4E official source notes

Verified against public British Council materials on 4 August 2026.

Authoritative format facts used in this release:

- Aptis General / Aptis ESOL General Speaking takes about 12 minutes and has four parts.
- Part 1 asks three personal questions; each response is 30 seconds.
- Part 2 uses one photograph and three responses; each response is 45 seconds.
- Part 3 uses two photographs and three responses; each response is 45 seconds.
- Part 4 contains three linked questions, one minute of preparation and one two-minute response.

Primary sources:

- British Council, “Prepare for Aptis ESOL General”.
- British Council, “Aptis Speaking Test Practice”.
- British Council, “Aptis General Technical Manual Version 2.2”.
